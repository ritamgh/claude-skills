# Lens lesson page, zine theme (assets/themes/zine.html)

Scope: the single lesson page rendered from one lesson JSON. Mode: Read. Large monitor first, phone usable.
Audience/job: one developer-researcher learning a codebase; reads for long stretches, returns days later.
Constraints: every lesson-schema capability keeps working (see PRODUCT.md); one self-contained HTML; light + dark.
Seed key: b54a4674 (challenger: hand-drawn-zine-explainer, chosen by the user).

## Direction contract

THESIS: A lesson is a friend's hand-made zine about this codebase: one long scroll of sketched panels where a real input travels through real code. It refuses the dashboard of side-by-side panels and tabs; one thing is in focus at a time.

OWN-WORLD: Dot-grid zine paper, black marker ink, three flat highlighters (yellow for the line that matters and changed values, pink for warnings/gotchas/wrong, teal for the route and right answers). Marker-lettered headings, a hand-written annotation voice, a calm readable sans body at 19px, real mono for code. Sketchy (rough) boxes and arrows; a magnifier-with-eyes mascot whose face marks think/right/oops/worry.

STORY: Title and the one-line answer, then the big sketched system map (the route draws itself on), then the trip: numbered panels per stop with narrative, code card with highlighter swipes and margin notes, memory sticky note, guess-first gates; then Break it, Why this way, Weak spots, Quiz, Glossary.

FIRST VIEWPORT: Marker title with a highlighter swipe, subtitle, mascot, and the whole system map at full width with labels readable from a metre away, route line drawn in teal.

SIGNATURE: The route draws on as you scroll, and the sticky sketched contents rail ticks off each stop as you pass it; the page reopens at the stop where you left off.

RISKS: Juvenile or noisy over an hour of reading; keep doodles to headings, map, margins and states, never inside paragraphs. Marker faces for headings only.
